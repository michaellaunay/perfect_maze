# Référence de l'API

Les docstrings sont rédigées en anglais ; cette page est générée à partir du
code source, identique à la [version anglaise](../en/api.md).

Tout ce qui suit est réexporté par le paquet `perfect_maze` :

```python
from perfect_maze import (
    Cell,
    Direction,
    Maze,
    OpenWall,
    RandRange,
    Wall,
    build_maze,
    printable_maze,
    record_maze_construction,
    __version__,
)
```
